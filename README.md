# Pico Programming with C
C programming on the Raspberry Pi Pico with RP 2040 chip.

`Pico SDK` is being used for programming.

GPIOs `20, 21, 22` are LEDS, and GPIOs `7, 8 ,9` are buttons defined with pull up resistors.

The hardware used (for now... Updated everytime expanding)
* Pico Debug Probe
* Raspberry Pi Pico W
* Development Kit
